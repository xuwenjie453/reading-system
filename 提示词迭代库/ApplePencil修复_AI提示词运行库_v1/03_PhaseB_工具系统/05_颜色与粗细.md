# 颜色与粗细 Prompt

> 状态：**ACTIVE**  
> 运行库版本：**v1.0**  
> 生成日期：**2026-09-07**

每种 writing tool 独立记忆 color/width。

例如：
```text
Pen         black / thin
Pencil      gray / medium
Highlighter yellow / wide
```

UI：
- 3–5 个粗细视觉档；
- 5–8 个常用颜色；
- 最近颜色；
- 可接系统 Color Picker。

不要显示工程浮点数给用户。

从 Highlighter → Pen → Highlighter：
> 必须恢复原 highlighter color/width。
