# 圆形 Current Tool Button Prompt

> 状态：**ACTIVE**  
> 运行库版本：**v1.0**  
> 生成日期：**2026-09-07**

实现 Reader 屏幕侧边浮动圆形按钮。

要求：
- 44–52 pt 左右；
- screen overlay；
- 不参与 CanonicalDocument layout；
- 显示当前 active tool icon；
- 显示简洁颜色状态；
- Pencil/finger 都可点击；
- 点击展开/收起 palette；
- 不因按钮存在减少正文宽度。

当前 Eraser 时显示 eraser；Highlighter 时显示 marker。

按钮只展示真实 InkToolController state。
