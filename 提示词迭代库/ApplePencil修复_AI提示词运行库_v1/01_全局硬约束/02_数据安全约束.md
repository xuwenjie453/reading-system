# Annotation 数据安全约束

> 状态：**ACTIVE**  
> 运行库版本：**v1.0**  
> 生成日期：**2026-09-07**

任何修改前：
- 识别当前 PKDrawing 的持久化位置；
- 识别 annotationRevision / layoutEpoch；
- 对目标数据建立 backup；
- 不覆盖原 drawing blob。

Migration 必须记录：
```text
migrationID
annotationID
fromLayoutEpoch
toLayoutEpoch
drawingHashBefore
drawingHashAfter
appliedAt
```

如果无法证明旧 Drawing 必须 transform：
> 不 transform。

如果字体变化导致非线性 reflow：
> 保留 Legacy Layout，不做 affine 猜测迁移。
