# 坐标系统不变量

> 状态：**ACTIVE**  
> 运行库版本：**v1.0**  
> 生成日期：**2026-09-07**

目标层级：

```text
Document Semantic Structure
→ Canonical Layout
→ Canonical Body Coordinates
→ Viewport Transform
→ Physical Screen
```

Apple Pencil 和 PKDrawing 永远工作在 Canonical Body Coordinates。

### 必须成立

```text
TextSurface.frame == CanonicalBodyView.bounds
PencilCanvasView.frame == CanonicalBodyView.bounds
```

Canvas：
```text
transform == identity
layer affine transform == identity
contentOffset == .zero
contentInset == .zero
zoomScale == 1
contentSize == CanonicalBodyView.bounds.size
```

如果当前代码做不到这些，请解释为什么，并重构结构；不要通过更多 offset 补偿。
