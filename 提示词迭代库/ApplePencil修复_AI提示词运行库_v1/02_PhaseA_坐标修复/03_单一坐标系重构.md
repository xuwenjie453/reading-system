# 单一 Canonical Coordinate Space 重构 Prompt

> 状态：**ACTIVE**  
> 运行库版本：**v1.0**  
> 生成日期：**2026-09-07**

将 Reader 重构为：

```text
ReaderViewController
└── ReaderViewportScrollView
    └── CanonicalDocumentView
        ├── MetadataHeaderView
        └── CanonicalBodyView
            ├── TextSurface
            └── PKCanvasView
```

### 目标

- TextSurface 与 Canvas 同 frame；
- CanonicalBodyView 是几何真源；
- PKCanvasView identity；
- ReaderViewport 负责整体 scroll/zoom；
- Canvas 不自行适配正文 scale；
- font/margin 仅影响 Text LayoutProfile。

### 不能做

- Canvas `.transform = scale(...)`
- SwiftUI `.scaleEffect` 只套在 Canvas
- 用 contentInset 把 Canvas“推到文字下面”
- 用 Canvas contentOffset 追随 Reader
- 同时 outer zoom + inner zoom

修改后增加 Debug assertions。
