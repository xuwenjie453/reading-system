# 系统测试策略

> 状态：**CANONICAL**  
> 设计基线：**v1.0-canonical**  
> 整理日期：**2026-09-07**

## Deterministic Unit
Graph invariants、depth、View→Focus、timing math、scheduler priority、revision、idempotency、transactions。

## Prompt Fixtures
NO_OP/EXTEND/CREATE、chunk boundary、title/summary、navigation intent。Hard constraints 必须 100% 通过。

## Integration
CREATE→Store→Journal→iPad mock；EXTEND→Patch→Reader append；Annotation→Outbox→Mac ACK；Reconnect→Snapshot→Session baseline。

## Crash/Recovery
在 transaction 各 commit point 注入 crash，验证 rollback/recover。

## Real Device
iPad + Pencil 真机验证 low-latency handwriting、finger scroll、rotation、lock/wake、Wi-Fi change。

## Prompt Regression
新 Prompt 先 historical replay/shadow，比较 CREATE/EXTEND rate、depth、duplicate suppression、schema violation、golden cases。v1 不做随机 live A/B 写真实 Graph。

## Performance
至少 100-node Graph、20k–30k Chinese chars Node、50+ Segments、较重 PKDrawing、连续 Patch。

## Release Blocker
Ink 丢失/错位、duplicate content、Graph corrupt、wrong Focus、stale nav 抢页、offline recovery failure。
