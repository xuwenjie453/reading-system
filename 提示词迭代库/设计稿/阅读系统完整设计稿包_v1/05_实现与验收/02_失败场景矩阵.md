# 失败场景与预期行为矩阵

> 状态：**CANONICAL**  
> 设计基线：**v1.0-canonical**  
> 整理日期：**2026-09-07**

| 场景 | 必须发生 | 禁止发生 |
|---|---|---|
| Mac 在 CREATE 中崩溃 | 未 commit txn rollback | 半个 Node |
| GraphPatch 重发 | dedup 一次效果 | Segment 重复 |
| iPad apply 后 ACK 前崩溃 | 重启恢复并重 ACK | 重复应用 |
| Pencil 离线 | 本地保存+outbox | 禁止写字 |
| Mac 重启 | 自动重新认证/同步 | 重新 Pair |
| iPad 锁屏 | 正常离线/恢复 | 当成 SKIP |
| Episode crash | INTERRUPTED | 负 Interest |
| semantic index 坏 | rebuild derived | Canonical 不可读 |
| Prompt source 被手改 | immutable snapshot 不变 | provenance 漂移 |
| 用户已去 C，CREATE B 完成 | B 创建，留 C | 抢页 |
| Content Snapshot | 修 CONTENT | 清空 Ink/Layout |
| Annotation conflict | 保留两份 | 静默覆盖 |
| source 删除 | mark MISSING，历史保留 | 删除 Graph/Ink |
| 用户“下一块” | explicit continuation | Temporal 插队 |
| App 长时间闲置 | 极弱/无兴趣影响 | 因分钟数明显加分 |
