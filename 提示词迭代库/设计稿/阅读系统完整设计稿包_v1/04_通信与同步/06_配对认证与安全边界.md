# 配对、认证与安全边界

> 状态：**CANONICAL**  
> 设计基线：**v1.0-canonical**  
> 整理日期：**2026-09-07**

## 身份
永久身份 = device_id + cryptographic identity，不是 IP/设备名。

## Key Storage
Mac private key → macOS Keychain；iPad private key → Keychain。普通 JSON/SQLite 不存私钥。

## 初次 Pairing
临时安全会话 → exchange public identities → derive/display same short code → 用户确认 → save trust。

## 后续认证
双方 challenge/response 或等价签名验证。若 Keychain identity 丢失，不静默建立新信任，进入 PAIRING_REQUIRED。

## API 边界
iPad 只连接 Reading Bridge protocol，不能访问 Reading Core Admin API。Core API 只监听 loopback/Unix socket，不默认开放 LAN。

## Prompt Package 安全
v1 Prompt package 只允许 Markdown/JSON/schema/fixtures；不把任意 shell/python executable 当“提示词包”自动执行。
