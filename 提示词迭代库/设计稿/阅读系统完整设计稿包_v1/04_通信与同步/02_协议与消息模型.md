# 同步协议与消息模型

> 状态：**CANONICAL**  
> 设计基线：**v1.0-canonical**  
> 整理日期：**2026-09-07**

## Envelope
所有消息逻辑上：protocol_version、message_id、session_id、sender_device_id、type、sent_at、payload。可靠方向可额外带 server_seq/client_seq。message_id 用于 dedup。

## 四个 Domain
### CONTENT
Block、Node、Title、Summary、Segments、Edges、graph metadata。Mac origin / durable authority。
### PRESENTATION
Graph coordinates、AUTO/USER_PINNED、layout revision。主要 iPad origin，Mac durable。
### SESSION
active graph、ViewState、navigation。高频 bidirectional，独立于 graph_revision。
### ANNOTATION
PKDrawing。iPad origin，Mac durable backup/final warehouse。

## Permanent IDs
协议引用 graph_id/block_id/node_id/segment_id/edge_id 等，绝不使用 title/path 作为身份。

## Revision 分离
graph_revision、layout_revision、annotation_revision、view_revision/session epoch、protocol_version 分开。不能一个 revision 混所有 Domain。

## Encoding
v1 控制/内容可用 JSON UTF-8；大型 PKDrawing 可 binary frame + JSON header。具体字段名可演化，但语义不变量不能变化。
