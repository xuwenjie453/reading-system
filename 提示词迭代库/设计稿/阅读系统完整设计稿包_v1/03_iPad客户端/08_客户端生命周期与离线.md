# iPad 客户端生命周期与离线行为

> 状态：**CANONICAL**  
> 设计基线：**v1.0-canonical**  
> 整理日期：**2026-09-07**

## Root State
```text
BOOTSTRAPPING → UNPAIRED/OFFLINE_CACHED → DISCOVERING → CONNECTING → AUTHENTICATING → SYNCING → READY
```
断开：READY → OFFLINE_CACHED，不回空白首页。

## Local-first Navigation
双击 Node 立即本地进入并持久化 ViewState，然后发 ViewCommitted。不能等 Mac 批准才打开页面。

## Background/Kill
进入后台尽量 flush current annotation/view/critical outbox，但可靠性必须来自平时持续 commit，而非依赖无限后台时间。

## Lock/Wi-Fi/Sleep
锁屏、网络切换、Mac sleep 都是正常断线。恢复后重新 authenticate/sync，不要求重新 Pair。

## Reconnect
Auth → checkpoints → 保护双向未确认本地数据 → content/layout/annotation sync → new session epoch → iPad VIEW_SNAPSHOT → READY。

## Offline Focus
iPad 本地知道自己的 View，但 Mac 在断线期间不能把 LastKnownFocus 当实时 authority 做新一轮自动 mutation。重连后以 iPad 当前 View 建 baseline。

## Old Auto-nav
旧 epoch 的 CREATE auto-nav 全失效。用户明确导航若仍有意义，由 Mac fresh reissue。
