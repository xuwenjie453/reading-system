## 技术方向
具体技术细节由实现 AI 负责，但推荐边界：Swift；SwiftUI App Shell；UIKit Reader/Topology；PencilKit；Network.framework；CryptoKit/Keychain；SQLite + Blob files；Swift Concurrency/Actors。

最低 iPadOS 版本由真实设备/Xcode 支持确定，不得为了 API 便利改变产品不变量。

## 分层
Domain Model、Wire DTO、Persistence Record、UI Model 分开。用强类型 GraphID/BlockID/NodeID/SegmentID/MessageID 等避免 String 混用。

## Actors
核心建议：ClientStoreActor、TransportActor、SyncEngineActor、SessionEngineActor。AppModel 只是 MainActor UI 投影，不是数据库。

## Topology
UIKit TopologyViewController + zoom/pan canvas + CALayer edges + node views。v1 不主动上 Metal/SpriteKit，除非压力测试证明必要。

## Reader
ReaderViewController + `ReaderSurface` abstraction。真正高风险是 PencilKit + outer scroll/zoom + text selection 的手势组合，必须做真机 spike。若具体 surface 实现更换，不应影响 Domain/Store/Sync。

## Store
SQLite 保存结构/revision/outbox/session；PKDrawing 等大 Blob 用文件 + DB pointer/hash。所有 DB 操作进入 ClientStoreActor。

## Mock Server
先开发 MockReadingServer，与真实 Mac 共享 ReadingProtocol，用于验证 Fresh/Temporal/EXTEND/CREATE/断线/revision mismatch。
