# iPad 本地缓存、Outbox 与持久化

> 状态：**CANONICAL**  
> 设计基线：**v1.0-canonical**  
> 整理日期：**2026-09-07**

## Cache 定位
不是 Mac Canonical Store 的替代品，但离线时必须是可靠工作副本。

## 本地数据域
CONTENT cache、PRESENTATION、ANNOTATION、SESSION、INBOX dedup、OUTBOX、sync checkpoints、pairing metadata（非私钥）。

## 私钥
长期 device private key 只能放 Keychain，不进入 SQLite/UserDefaults。

## Annotation Blob Transaction
1. write temp blob；
2. flush；
3. atomic rename；
4. DB transaction；
5. update annotation pointer/hash/revision；
6. enqueue outbox；
7. commit。
旧 Blob 可短期保留，防 crash 中间态丢数据。

## Outbox
ViewCommitted、LayoutPatch、AnnotationSnapshot 先本地持久化再发送。Annotation/Layout 同对象的多次未发送更新可 coalesce 到最新。

离线导航不需要重播所有历史；reconnect 时以当前 VIEW_SNAPSHOT 作为新 Session baseline。

## App Kill
重启从 ClientStore 恢复 cached graph、last semantic view、pending outbox、annotations、layout；先进入 OFFLINE_CACHED，再尝试连 Mac。
