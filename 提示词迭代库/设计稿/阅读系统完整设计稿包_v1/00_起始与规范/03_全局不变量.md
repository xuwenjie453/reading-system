# 全局不变量

> 状态：**CANONICAL**  
> 设计基线：**v1.0-canonical**  
> 整理日期：**2026-09-07**

## 内容
1. ContentBlock 永远不可 EXTEND 或被 AI 重写。
2. Node Body 只能追加新 Segment；旧 Segment 不移动、不编辑、不删除。
3. 一轮 QA 最多一个 Graph 结构动作。
4. 一个 Block 在 v1 恰对应一张 Graph。
5. 每个 Node 恰有一个 parent，图无环。
6. v1 不自动跨 Graph 连接、merge、move、reparent、retro split。
7. 全图相似检索只有 CREATE 抑制权，不能自动 EXTEND 远处 Node。

## Focus / Session
1. `Focus = derive(iPad ViewState)`。
2. TOPOLOGY_VIEW → Block；BLOCK_VIEW → Block；NODE_VIEW(N) → N。
3. Anchor Card selection 不改变 Focus。
4. Mac 不存在公开 `set_focus`。
5. Curator 使用 frozen TurnContext，不使用完成时实时 Focus。
6. CREATE 自动导航是 conditional，不能覆盖用户之后的 iPad 导航。

## 存储 / 同步
1. Mac 是 CONTENT 长期最终权威。
2. iPad 合法产生 PRESENTATION、ANNOTATION、SESSION 事件，Mac 长期持久化。
3. Canonical mutation 先 durable commit，再 emit。
4. ACK 只能在 durable apply 后发送。
5. at-least-once + dedup = one effect。
6. Patch 只有 local revision == base revision 才应用。
7. Content Snapshot 不得覆盖 Annotation/Presentation。
8. 断线不能丢 ACKed 数据。

## Pencil / Layout
1. Ink 与正文分层。
2. Ink 绑定 concrete entity。
3. 有 Ink 的正文使用 stable canonical layout。
4. EXTEND 只向下追加，旧正文几何不变。
5. Title/Anchor Summary 不属于可写正文坐标平面。
6. PKDrawing vector data 是笔迹真源。
7. v1 不自动 OCR，也不把手写自动变成 Node。

## AI
1. AI 可做语义判断，但不能直接写 Canonical Store。
2. 所有 mutation 经过 Reading Core / Store Service。
3. Prompt 不能覆盖 hard policy。
4. 正式 Prompt Version 注册后 immutable。
5. 所有生成/决策有 provenance。
