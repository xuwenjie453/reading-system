# 设计冲突时的裁决规则

> 状态：**CANONICAL**  
> 设计基线：**v1.0-canonical**  
> 整理日期：**2026-09-07**

冲突时优先级：
1. `03_全局不变量.md`
2. 本包相应主题 CANONICAL 文档
3. `99_变更与废弃规则/`
4. 代码实现说明
5. 历史聊天/旧设计稿

典型冲突：
- 旧规则（已废弃）：CREATE 一完成就把新节点视为当前 Focus。新规则：先 conditional nav，只有 iPad VIEW_COMMITTED 后才派生 Focus。
- 旧：“scope_summary 隐藏” → 新：统一为 Anchor Summary，并允许 UI 预览。
- 旧：“需要 Pencil 模式” → 新：Pencil 落笔即写，手指滚动/缩放/UI。
- 旧：“停留越久兴趣越高” → 新：精确 dwell time 极弱，主动回访和认知事件为主。
- 旧：“CREATE 一定自动切页” → 新：auto-nav 可 stale。

未覆盖的新冲突，优先保护：数据不可变性 → 用户显式意图 → iPad 真实 View → 稀疏稳定图 → 自动化便利。
