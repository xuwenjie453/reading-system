# 系统设计总览

> 状态：**CANONICAL**  
> 设计基线：**v1.0-canonical**  
> 整理日期：**2026-09-07**

## 用户主流程
用户把 PDF、EPUB、TXT、Markdown、MOBI 等放入 Mac 的 `资料库/`。Mac 解析为一系列 ContentBlock，每个 Block 唯一对应一张 ContentGraph。Mac 将某张图推给 iPad；新内容默认进入 Block 正文。用户在 Mac 与 AI 对话，重要认知由 Graph Curator 沉淀为 ContentNode；iPad 可以对 Block/Node 直接 Apple Pencil 批注。

结束当前 Graph 后，Reading Scheduler 在顺序新内容与过去真正感兴趣的旧 Graph 之间做选择，但只在自然阅读边界调度，绝不打断正在阅读的 Graph。

## 顶层架构
```text
用户
├── MacBook
│   ├── Codex / zcode
│   ├── Prompt Runtime
│   ├── Context Builder
│   ├── Reading Core / ReadingDaemon
│   ├── Canonical Store
│   ├── Interest / Timing / Scheduler
│   └── Reading Bridge
└── iPad
    ├── Topology
    ├── Reader
    ├── Apple Pencil
    ├── Local Cache
    └── Sync / Session
```

## v1 设计哲学
v1 优先“稳定、可追溯、低干扰”，而不是功能量。明确不做跨 Graph 自动知识图谱、多设备 CRDT、iPad AI Chat、自动 OCR 手写、掌握度/复习任务系统、自动 merge/reparent/retro split。
