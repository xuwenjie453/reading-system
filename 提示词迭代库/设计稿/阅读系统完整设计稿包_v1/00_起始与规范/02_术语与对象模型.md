# 术语与对象模型总表

> 状态：**CANONICAL**  
> 设计基线：**v1.0-canonical**  
> 整理日期：**2026-09-07**

## Document / SourceVersion / ParseRun
- **Document**：逻辑资料，永久 `document_id`。
- **SourceVersion**：某份精确文件内容版本，以 fingerprint 识别；移动/重命名不改变身份。
- **ParseRun**：一个 SourceVersion 在特定 parser/profile/config 下的一次不可变解析结果。

## ContentBlock
作者原始资料的稳定阅读单元。正文不可被 AI 或用户改写。

主要字段：`id/document_id/parse_run_id/ordinal/title/anchor_summary/source_range/content`。

## ContentGraph
每个 ContentBlock 唯一对应一张 Graph。v1 为 rooted tree；Block 是 root，Node 每个恰有一个 parent。Edge 只表示“创建时从哪个认知焦点生长”，不表达支持、反驳、因果等类型。

## ContentNode
围绕一个稳定认知议题可持续追加的长期认知记录。不是聊天气泡，不是 QA 转录。

```text
ContentNode
├── id
├── title
├── anchor_summary
├── parent_id
├── depth
└── body
    ├── segment_001
    ├── segment_002
    └── ...
```

## Title
Node 在 CREATE 时生成，通常稳定不改；中文建议 6–18 字，软上限约 24 字。

## Anchor Summary
动态认知锚点，用于 UI 预览、ScopeFit、duplicate suppression、Context Builder、NodeComplexity。它取代早期隐藏 `scope_summary` 的设计。

## ViewState / Focus / TurnContext
- ViewState：iPad 当前真实语义页面。
- Focus：由 ViewState 派生的认知焦点。
- TurnContext：用户提交 QA 瞬间冻结的 graph/focus/view revision/session epoch 等。

## ReadingEpisode
一次进入 ContentGraph 直到 END、SKIP 或切换出去的行为单元。Interest 按 Episode 更新，而不是每动作加分。
