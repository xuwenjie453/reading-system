# 两份最终成果与交付边界

> 状态：**CANONICAL**  
> 设计基线：**v1.0-canonical**  
> 整理日期：**2026-09-07**

## 成果 A：MacBook 端提示词运行库 / 阅读系统运行包
不是一个超级 system prompt，而是一套可由 zcode/Codex 驱动的体系：Prompt Registry/Profiles、Responder、Graph Curator、Parser roles、Context Builder、Reading Core/ReadingDaemon、Canonical Store、Scheduler、Interest/Timing、Reading Bridge、Audit/Recovery。

用户工作区：
```text
阅读系统/
├── 资料库/          # 用户控制
├── 提示词迭代库/    # 用户控制
└── 系统数据/        # 系统控制
```

## 成果 B：iPad 阅读器客户端
完整 Xcode 工程，支持 Pairing、Topology、Block/Node Reader、Apple Pencil、Stable Layout、Offline Cache、Reconnect、Snapshot/Patch Sync、Session Navigation、Recovery。

## 共享契约
两端必须共享同一语义定义：ContentGraph、GraphSnapshot、GraphPatch、LayoutPatch、AnnotationSnapshot、ViewState、NavigationCommand、ACK/Error。不能两端各自演化不同含义。
