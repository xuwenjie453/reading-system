# 审计、版本、迁移与恢复策略

> 状态：**CANONICAL**  
> 设计基线：**v1.0-canonical**  
> 整理日期：**2026-09-07**

## Decision Audit
每个 Curator 决策保存结构化记录，而非私有 chain-of-thought：qa_turn、graph/focus、decision、quality、scope、duplicate、complexity、prompt/model/context provenance、created object IDs。

## Prompt Provenance
AI 产物引用 immutable Prompt Snapshot + role hash。Prompt activation 不重写历史 Segment。

## 版本分离
Store schema、API、Protocol、Prompt Contract、Interest model、Timing model 分开版本化。

## Migration
所有 Canonical schema migration deterministic + journaled + recovery point + validation + rollback。AI 不能自由修改 schema。

## Integrity
Startup fast + 可请求 deep integrity。Derived index 可删重建；Canonical 缺失不猜。

## Source Missing
源文件删除 → mark MISSING，保留 Block/Graph/Node/Annotation；相同 fingerprint 回来可 rebind。v1 不自动清除历史认知。
