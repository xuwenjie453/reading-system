# ReadingDaemon 启动、恢复与生命周期

> 状态：**CANONICAL**  
> 设计基线：**v1.0-canonical**  
> 整理日期：**2026-09-07**

## 启动顺序
Canonical Store → Transaction Recovery → Fast Integrity → Schema/Migration → Core Services → Reading Bridge → Device Sync → Session Reconciliation → READY。永远先恢复本地一致性，再连 iPad。

## Boot
single instance lock、boot_id、clean shutdown marker；NORMAL/RECOVERY/SAFE/MIGRATION boot。stale lock + 无进程 → Recovery Boot。

## Pending Txn
未 commit 的 Graph CREATE/EXTEND 默认 rollback。ParseJob 可 checkpoint，但正式 ParseRun 只有完整 commit 后才 canonical。

## Integrity
Fast check：manifest、DB、pending txn、active prompt profile、graph root/basic refs、sync seq。Deep hash scan 不每次启动。Canonical corruption→SAFE_MODE；Derived index corruption→REBUILD_REQUIRED，不阻基本阅读。

## Migration
写服务锁定；先 recovery point；deterministic migration；validate；失败 rollback。禁止 AI 临场猜 migration。

## Device Offline
CORE_READY + DEVICE_OFFLINE 是正常状态。Mac 可解析/查询/一般对话，但 LastKnownFocus 不可用于新一轮自动写图。

## Reconnect
auth → new epoch → data sync → iPad VIEW_SNAPSHOT → Focus baseline。Mac 重启不能主动恢复 LastKnownFocus 页面。

## Interrupted Episode
crash 时 OPEN Episode 标 INTERRUPTED，不当 SKIP/负兴趣。

## Sleep/Wake
可靠性不依赖 sleep hook；Wake 重新验证 network/session。

## Auto Navigation Recovery
CREATE conditional nav 不跨 epoch；用户 explicit nav 可在有限恢复窗口内 fresh reissue。

## Safe Mode
允许 read/export/integrity/recovery copy，禁止 CREATE/EXTEND 等 mutation。
