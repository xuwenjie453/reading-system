# 已被覆盖 / 废弃的旧决策清单

> 状态：**CANONICAL-META**  
> 设计基线：**v1.0-canonical**  
> 整理日期：**2026-09-07**

以下规则若出现在早期聊天或旧 md 中，应视为**废弃**。

## 1. CREATE 后直接 `Focus = new_node`
废弃。最新：CREATE commit → conditional NavigationCommand → iPad VIEW_COMMITTED(new_node) → Mac derive Focus=new_node。

## 2. CREATE 后一定自动进入新 Node
废弃。用户若在 AI 处理中已导航，auto-nav 必须 stale，不能抢页。

## 3. 隐藏 `scope_summary`
废弃。统一为 Anchor Summary，既服务语义判断，也可用户预览。

## 4. Node Title 是唯一 Scope Anchor
废弃。Title 稳定，但 ScopeFit 主要依赖 Anchor Summary + relevant body/context。

## 5. 必须先进入 Pencil 模式
废弃。Pencil 在正文可写区落笔即写；finger 默认滚动/缩放/UI。

## 6. 精确秒/分钟停留时间显著提高 Interest
废弃。App 可能闲置；时间只做极弱粗粒度辅助，主动回访/认知加工/跨时间重访更重要。

## 7. Working memory 按固定分钟过期
废弃。主要按 Graph/session/topic 等事件边界重置。

## 8. Mac 离线时用 LastKnownFocus 自动 Curator 写图
废弃。LastKnownFocus 不具实时 authority。只有在线时已冻结 TurnContext 或用户明确 target 的操作可安全完成。

## 9. Prompt 是一个超级 system prompt
废弃。采用角色化 Modules + Profile + immutable snapshot + schema/policy validation。

## 10. 全图相似可自动跳去/修改旧 Node
禁止。v1 全图检索只有 CREATE suppression 权。

## 11. 动态文字 reflow 优先于 Pencil 坐标
废弃。有 Ink 的 Entity 优先 stable canonical layout；阅读放大主要 Zoom。

## 12. Scroll 到底自动 END
禁止。滚动位置不是阅读完成语义。
